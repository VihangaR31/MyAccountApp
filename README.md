# MyAccountApp
A simple React Native mobile app built using Expo for Mobile Application Development Practical 04.

## Features

- User registration form
- Form validation
- Password matching
- Data transfer between screens using Expo Router
- Review screen to check entered details
- Success screen with a personalized welcome message
- Age calculation using year of birth
- Warning for users under 18

## Technologies Used

- React Native
- Expo
- Expo Router
- JavaScript
- VS Code

## How to Run

```bash
npm install
npx expo start
```

Scan the QR code using the Expo Go app or run it on an Android emulator.
